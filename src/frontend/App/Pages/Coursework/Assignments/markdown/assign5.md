#### Asignment 5: In React, what are the different ways we can link to resources (e.g. Root Relative vs Document Relative)?

In React, there are two main ways to link to resources:

<li>  1. Document-Relative Paths (./ or ../) - Document-relative paths are relative to the current file's location.  </li>
<li> 2. Root-relative paths (/) - are often used for assets in the public folder, while document-relative paths are used for components and files within the src directory. </li>
